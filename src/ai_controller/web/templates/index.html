Elastic clusters

Configured clusters

Each session and autorun binds to one Elastic cluster. MCP SIEM tools use that cluster’s URL and credentials.

Add cluster

Use the Elasticsearch API URL when possible (usually port 9200). Kibana (5601) can be saved and tested, but search tools expect Elasticsearch. SIEM query skills include KQL, Lucene, EQL, Query DSL, and ES|QL (search_kql_query, search_lucene_query, search_eql_query, search_dsl_query, search_esql_query) — toggle them under Edit skills.

Default MCP skill vector

Copied onto every new cluster, which can then override it. Example: MSV:1/IRIS:N/SIEM:Y/EDR:N/SK:create_case=N

Activity log

Buttons on this page write here and to the browser console as [Elastic]. Server logs are in logs/debug.log under sami.web.elastic.

Connection

General

What the terminal shows, and the caps on each prompt.

Display

Off shows only the agent's reply. On renders the full JSON result in the terminal.

Live model round, reasoning, and each MCP tool, kept above the reply and separate from the JSON dump.

Investigation limits

Saved in config.json. The next session or autorun prompt uses these caps.

Default 12. How many times the model may answer and call tools before it must stop.

Default 8000. Longer tool output is cut off before the next model round.

Default 6000. How much of each thought or tool result stays in the live view.

Default 180. One model reply. A timeout is retried once, then the run stops.
